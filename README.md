# 🍽️ Savory — Restaurant Website

A premium, fully responsive restaurant website built with vanilla **HTML**, **CSS**, and **JavaScript**. Features a warm, food-inspired design with interactive menus, a testimonial slider, gallery lightbox, and a fully validated reservation system.

![Savory Restaurant](https://images.unsplash.com/photo-1517248135467-4c7edcad34c4?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

### 🎨 Design & UX
- **Premium warm palette** — food-inspired colors (terracotta, gold, cream)
- **Fully responsive** — mobile-first, works on all screen sizes
- **Smooth animations** — reveal-on-scroll, hover effects, floating elements
- **Custom preloader** — elegant loading screen on first visit
- **Fixed navbar** — transparent on top, solid on scroll
- **Mobile sidebar menu** — with dedicated close button & outside-click dismiss
- **Back-to-top button** — appears after scrolling down
- **Toast notifications** — for orders and form submissions

### 🍕 Interactive Sections
- **Hero** — animated counters, CTA buttons, scroll indicator
- **Featured Dishes** — filter by category (Mains, Pasta, Pizza, Desserts), load more, order buttons
- **About** — restaurant story, "Why Choose Us" list, floating award card
- **Testimonials** — auto-rotating slider with dots, pause on hover
- **Gallery** — masonry-style grid with lightbox viewer
- **Reservation** — fully validated booking form with live error messages
- **Contact** — clickable phone, email, address, and hours
- **Footer** — brand info, quick links, socials, dynamic year

### ⚙️ Functionality
- Category filtering for dishes
- "Load More" pagination
- Auto-advancing testimonial slider with manual dots
- Keyboard-accessible gallery lightbox (`Enter`/`Space` to open, `Esc` to close)
- Real-time form validation (name, email, phone, date, time, guests)
- Toast notifications on success
- Smooth anchor scrolling with offset for fixed nav
- Active nav link highlighting on scroll
